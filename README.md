# 🌐 Frontend Web - Elite Tickets

Este repositório contém a aplicação cliente (Interface do Usuário) para a plataforma de eventos e ingressos do desafio **Elite Dev**.

A aplicação foi construída visando **performance**, **componentização** e uma **experiência de usuário (UX) fluida** para os três papéis do sistema: **Organizador, Cliente e Portaria**.

## 🛠️ Tecnologias Utilizadas

* **Biblioteca Core:** React.js
* **Build Tool:** Vite
* **Estilização:** Tailwind CSS (com paleta de cores institucional customizada)
* **Roteamento:** React Router DOM

## 🎨 Design System (Paleta de Cores)

A interface utiliza uma paleta de tons de azul e ardósia configurada nativamente no Tailwind (`brand-100` a `brand-500`):

* `#cee5f2`
* `#accbe1`
* `#7c98b3`
* `#637081`
* `#536b78`

## 🚀 Como Executar Localmente

### 1. Instale as dependências

```bash
npm install
```

### 2. Inicie o servidor de desenvolvimento

```bash
npm run dev
```

A aplicação estará disponível em:

`http://localhost:5173`
